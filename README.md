# thebanri/tap

Homebrew tap for [Limoni Voice](https://github.com/thebanri/limoni-voice), a terminal-native,
end-to-end encrypted P2P voice chat with screen sharing.

```bash
# The command (macOS and Linux)
brew install thebanri/tap/limoni-voice

# Limoni Voice.app on macOS (opens limoni:// invite links, updates itself)
brew install --cask thebanri/tap/limoni-voice-app
```

The formula and cask are updated automatically by the Limoni Voice release workflow.
